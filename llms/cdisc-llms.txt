# CDISC

> CDISC (Clinical Data Interchange Standards Consortium) is a 501(c)(3) global non-profit that develops the
> data standards required for clinical research submissions — SDTM, ADaM, CDASH, SEND, ODM, Define-XML,
> Dataset-JSON, USDM and CDISC Controlled Terminology. The CDISC Library is the authoritative machine-readable
> source for that metadata, delivered as linked data over a REST API at https://library.cdisc.org/api.

Generated by API Evangelist from this repository's apis.yml and artifacts on 2026-09-17. CDISC does not
publish an llms.txt of its own (https://www.cdisc.org/llms.txt returned 404 on 2026-09-17).

Access: every operation requires an `api-key` request header. Keys are issued from the Azure API Management
developer portal at https://api.developer.library.cdisc.org/ after a CDISC Library account is approved
(members and open-source developers). The entire hosted surface is read-only — every published operation is
a GET. There are no published rate limits and no published pricing tiers.

## APIs
- [CDISC Library API](https://www.cdisc.org/cdisc-library): standards metadata — products, SDTM, ADaM, CDASH,
  controlled terminology, biomedical concepts. Base https://library.cdisc.org/api
- [Analysis Results Standard (ARS) API](https://library.cdisc.org/api): 17 read operations under
  /mdr/ars/packages for reporting events, analyses, methods, outputs and categorizations
- [CDISC CORE](https://www.cdisc.org/core): open-source conformance rules engine (CLI, not a hosted API)

## Operations
- GET /mdr/products — list published standards products (listProducts)
- GET /mdr/sdtm — list SDTM versions (listSdtmVersions)
- GET /mdr/sdtm/{version} — get an SDTM version (getSdtmVersion)
- GET /mdr/sdtm/{version}/classes — list classes in an SDTM version (listSdtmClasses)
- GET /mdr/sdtm/{version}/datasets — list datasets/domains (listSdtmDatasets)
- GET /mdr/sdtm/{version}/datasets/{dataset} — get a dataset with its variables (getSdtmDataset)
- GET /mdr/adam — list ADaM versions (listAdamVersions)
- GET /mdr/adam/{version} — get an ADaM version (getAdamVersion)
- GET /mdr/cdash — list CDASH versions (listCdashVersions)
- GET /mdr/ct — list controlled terminology packages (listTerminologyPackages)
- GET /mdr/ct/{packageDate}/codelists — list codelists in a CT package (listCodelists)
- GET /cosmos/v2/bc — list biomedical concepts (listBiomedicalConcepts)
- GET /cosmos/v2/bc/{conceptId} — get a biomedical concept (getBiomedicalConcept)
- GET /mdr/ars/packages — list ARS packages (api.products.ars.get_packages)
- GET /mdr/ars/packages/{package}/reportingevents — list reporting events
- GET /mdr/ars/packages/{package}/reportingevents/{reportingevent} — get a reporting event
